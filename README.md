# ☕ Meu Aprendizado Java

Bem-vindo ao meu repositório de estudos! Este espaço é dedicado a documentar minha jornada com a linguagem Java, desde os fundamentos de lógica até a construção de aplicações backend.

## 🚀 Objetivo
Praticar e consolidar conceitos essenciais de programação, focando em:
* **Lógica de Programação:** Estruturas condicionais, loops e algoritmos.
* **POO:** Programação Orientada a Objetos aplicada na prática.
* **Organização:** Manter um código limpo e um histórico de evolução constante.

## 📂 O que você encontra aqui?
* **[Logica-de-Programacao/](./Logica-de-Programacao/):** Exercícios iniciais como Análise de Crédito, Financiamento de Moto e desafios de lógica pura.
* **Exercícios de Fixação:** Pequenos programas para testar novos conhecimentos em tempo real.

## 🛠️ Ferramentas Utilizadas
* **Linguagem:** Java 25+
* **IDE:** Visual Studio Code
* **Versionamento:** Git e GitHub
